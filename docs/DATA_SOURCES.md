# 数据来源、缓存与授权风险

## 数据流程

统一 `MarketDataProvider` 隔离外部字段：AKShare 为主，BaoStock 用于历史日线补充/回退，确定性 Demo 保证离线可运行。代码规范化为 `000001.SZ` / `600000.SH`，统一 OHLCV、成交额、停牌、复权和元数据。

定时采集 → 字段转换和完整性检查 → 与 Parquet 缓存增量合并 → 指标/策略 → 会员从平台缓存读取。网页请求不会直连 AKShare 或 BaoStock。

Provider 具有最小请求间隔、明确连接/总超时、有限重试和指数退避。缓存记录 provider、真实/演示类型、更新时间、复权方式、过期状态与警告。网络失败后回退不会把 Demo 标成真实行情。

## 完整性与缺失

检查日期递增和唯一、OHLC 关系、非负成交量、合法价格。停牌日通过 suspended 标记处理；数据源缺失交易日不会被人为补成可成交 K 线。周 K 由已缓存日线重采样。

## 授权边界

AKShare、BaoStock 及其上游站点的使用条款、抓取限制、商业使用与再分发权需要运营方在正式收费前逐项确认。本项目的适配器实现不构成数据商业授权。不要把未经确认的免费接口描述为可商业再分发。

港股、美股和主流加密货币仅保留 Provider 扩展点。上线前应评估合法供应商、延迟、复权、交易日历和再分发许可；未接入时页面只显示“即将支持”。
